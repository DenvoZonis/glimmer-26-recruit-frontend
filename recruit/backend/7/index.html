7：Linux的使用

如果你看到这里，说明你对于前面java语言的学习已经掌握的不错了，首先，让我们给自己点个赞！

但是，对于编程语言的学习只是后端开发的冰山一角。接下来，让我们踏上新的旅程，开始对于Linux操作系统的学习。

TASK 0：前言

Section titled “TASK 0：前言”

你可能会觉得，我们平时使用的Windows操作系统已经够方便了，我们已经习惯了它提供的图形化操作界面,为啥还要费心思去学Linux呢？其实，在计算机世界的另一端，Linux才是当之无愧的主角。当前全球近90%的服务器都运行在Linux系统上，从你使用的安卓手机，到SPACEX的大火箭，其中无处没有Linux的身影。

但是，我们的电脑原生的操作系统就是Windows，如果强行更换主机的操作系统，过程麻烦不说，还可能导致数据的丢失。为了解决这个问题。我们一般采用虚拟机内安装Linux系统，以达到方便日常使用的目的。

什么是虚拟机呢？简而言之，它就是在你的Windows里，模拟出一台独立的“虚拟”电脑，它就像一个可以随意摆弄的沙盒，你在里边进行的任何工作都不会影响到你的主机系统，即使虚拟机内部崩溃了也只要删掉重建甚至恢复快照即可，而不会影响你的Windows。此外，虚拟机本质上就是一个“文件夹”，你可以随时拷贝出来带到其他宿主机上进行使用，而且，虚拟机的快照功能可以记录任意时刻虚拟机的状态，方便你（万一手滑把系统搞崩了）恢复数据，好处多多啊！

在本次考核中，我们选择的虚拟机软件是VMware Workstation，并采用Ubuntu发行版。这是目前对新手最友好，社区资源丰富，功能多样的一版，推荐使用。

闲话少叙，让我们正式开始吧。

TASK 1：安装并配置VMware

Section titled “TASK 1：安装并配置VMware”

VMware Workstation有多种途径可以下载。如果想在官网进行下载的话，则需要访问 https://www.vmware.com/products/workstation-player.html ，第一次登录的话需要用自己的qq邮箱注册账号。在官网中找到VMware Workstation Player，注意选择Windows版本的，接下来只要下载即可，选用默认配置（但是遇到“Install Windows Hypervisor Platform (WHP)”选项和”将 VMware Workstation Player 添加到系统 PATH”选项，一定要记着勾选上）。如果觉得在官网下载太慢，也可以在联想应用商城或者是火绒自带的应用商城进行下载，都可以正常使用。

接下来就要下载Ubuntu的镜像文件。什么是镜像呢？我们可以把它理解成一个光盘，你要是给一个白板电脑装Windows系统，需要用U盘或是光盘里存着的Windows操作系统文件，这里的镜像也是一个道理，VMware会用这个“光盘”给虚拟机装上操作系统。

我们选择在清华大学官方的镜像网站下载文件。访问 https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/ ，并选择24.04版本的Ubuntu镜像（24.04 表示24年4月发布的版本，是一个长周期支持版本，比较稳定）。点进24.04文件夹之后，在列表里找到ubuntu-24.04-desktop-amd64.iso文件并下载。这样，我们的准备工作就完成了！

现在就可以进行新虚拟机的配置工作。由于内容较多，这里我提供一篇CSDN博客，里边详细介绍了虚拟机的初始配置流程，大家只需要按图索骥，一步一步来即可完成。（这篇博客是以22.04版本为例子，但是步骤是大差不差的，可以参考）

CSDN博客：https://blog.csdn.net/qq_62888264/article/details/145102532

TASK 2：了解Linux的基本命令和结构

Section titled “TASK 2：了解Linux的基本命令和结构”

上回书说到，我们使用Linux操作系统时，不像Windows那样会频繁使用图形化操作界面，大部分的工作都是在终端中通过各种命令来完成的。这一节我们就来了解一下Linux操作系统的各种命令。

不过，在敲指令之前，我们要先面对一个问题：Linux的文件系统是什么样的？

打开Windows的“我的电脑”，你会看到Windows中的文件散布在各个盘中，C盘，D盘等等，在盘里边又有各种文件夹，其中存储着各种文件。但是你要是打开虚拟机桌面那个本地文件夹，里边是找不到盘符的。这是因为Linux的文件结构区别于Windows，它是一个树状的结构，所有文件夹都挂在一个叫“/”的目录下，这个目录也叫做根目录。在这个根目录下，有etc,usr,tmp等等文件夹，它们各司其职，撑起了Linux这棵大树。

TASK 3：vim文本编辑器

Section titled “TASK 3：vim文本编辑器”

现在，你已经对Linux系统的命令有了初步了解，也已经尝试过用命令在终端写入文本内容。但是你是否想过，如果我想正儿八经的编辑一个文本文件，就像在Windows系统里用记事本那样，该怎么办？其实，在Linux终端里自带了一个叫vim的文本编辑器，我们都是使用它完成文本编辑工作的。

当你想要用vim给一个文件编辑文本内容时，在终端输入vim + 文件路径 ，即可进入vim命令模式。如果这个文件路径不存在，那么这个命令是会自动创建该文件的。接下来我们用一个简单的例子尝试一下吧！

第一步，在终端输入vim hello.txt 如果你之前没创建过这个文件的话，vim会自动帮你创建。回车之后就进入了vim的命令模式，还不可以输入文件内容。

第二步，按i键，即可进入输入模式，在文档中输入hello,world

第三步，按esc键，退出输入模式，回到命令模式。

第四步，按冒号，退出到底线命令模式。在底部输入wq，即可保存文件并退出vim编辑器

在上边的例子中，我们体验了vim最基本的几个命令。但是vim之所以被认为是一款功能非常强大的文本编辑器，其核心就在于命令模式中多样且作用复杂的命令。比如a键，可以在当前光标后面一个位置进入输入模式，I键则可以在当前光标所在行的开头进入输入模式等等。（注意，这些按键都是在命令模式下才可以使用的，别在输入模式或底线命令模式这么干）

TASK 4：认识IP与端口

Section titled “TASK 4：认识IP与端口”

在这一节中，我们将去了解网络世界最基本的单元门：IP地址与端口，并且利用这些知识进行Windows和Linux的远程连接。

首先，什么是IP地址呢？我们可以把它理解成网络世界的门牌号，计算机之间想要相互通信需要这样一个“地址”才能够进行。在你的Linux终端输入命令 ip addr就可以查看你的虚拟机的IP地址了。这时候你会看到终端跳出了一堆信息，别慌，真正的IP地址就在ens33那一行的后面，一般来说都是192.168开头，这就是你的虚拟机的地址。

那什么又是端口呢？端口可以理解成一个地址上开的不同的门。我们的计算机里同时运行着成千上万个程序，它们需要的信息各不相同，如果这些信息都是通过IP这个大地址来配送，未免太过混乱。端口则像是给这些程序分别开的小门，某个程序需要的信息都从这个门进行传递，效率自然会高不少。

端口号的范围为0-65535，其中前1024个是“知名端口”，是系统默认预留给操作系统和核心服务的，比如ssh远程连接默认的就是22号端口，网页服务默认的是80号端口。如果以后我们要写一个服务，一般不要占用这些知名端口。了解这些基本信息后，我们就可以借助你得到的IP信息来建立Linux远程连接了。

我们在本TASK中采用FinalShell进行远程连接。不过这个程序不是Windows系统自带的，你可以在应用商城或是直接找官网进行下载。配置过程并不复杂，如果有不明白的地方，可以查看B站视频或是询问AI解决。这里提供一个教程视频：https://www.bilibili.com/video/BV1n84y1i7td/?spm_id_from=333.788.videopod.episodes&vd_source=25ee6491b64b6e35a8ff8306e8e50b4c&p=8

TASK 5：用户与权限

Section titled “TASK 5：用户与权限”

恭喜你，来到了Linux部分的最后一节。在开始之前，我想问你几个问题：你在之前开荒Linux，下载各种文件的时候，是否注意过教程会经常让你切进root用户，或是用sudo命令借用root权限？当你用ls命令查看文件夹内容时，有没有看到在文件夹前边有一串rwx之类的不可名状“乱码”？其实这就涉及到了Linux中用户与权限方面的内容。

你可能会感到奇怪：我在Windows上下游戏，找资料的时候，也没人让我输入密码，切换用户啊，为什么Linux需要我这么干呢？其实，比起Windows中你的“一家独大”，Linux是一个“多人合租”的系统。比如要维护一个跑在Linux上的服务器，有的人负责管理数据库，有的人只是看看系统日志，如果他们都获取了最高权限，可以随意更改工作内容，岂不是乱了套？为了避免这种情况，Linux包含的用户和权限系统就有了作用。

你的任务：

  1. 学习什么是root用户，什么是用户组，该怎样配置新的用户和用户组？
  2. 既然root这么强大，我能不能一直开着root呢？会有什么危害吗？谈谈你的看法

讲完了用户，我们来看看权限相关的内容。在终端输入ls -l 命令，你会看到一长串的文件和文件夹，前边都带着rwx之类的字符串。这其实代表着这个文件/文件夹的使用权限。r是“读”权限，你可以用cat或是vim命令查看文件内容，对于文件夹，则是可以通过ls命令查看其中的内容但无法通过cd进入。w是“写”权限，你可以修改，删除，覆盖文件的内容。x是“执行”权限，对于程序是可以执行它，对于文件夹则是可以cd进入其中。

看完这个你可能还是会有疑问。既然这三个就能表示全部权限，为什么还要写一长串呢？还记得刚才提到的用户和用户组吗？一个文件可不止是给你看的，那一长串内容就是为了确定不同用户对于该文件的使用权限而设置的。第一组rwx规定的是主人的权限，第二组是和主人在同一用户组的用户的权限，第三组则是其他人的权限。

那么，这些权限也是可以修改的吗？当然可以！通常来说，root和主人可以通过chmod命令修改一个文件或文件夹的权限，这就是你需要自己学习的内容了。

你的任务：

  1. 自己学习chmod命令，尝试修改一个文件的权限，把你输入的命令截图保存
  2. 天天打rwx还是太吃操作了，有什么简单又强势的方法来简化呢？有的兄弟有的，去学习怎么用数字简化权限表述吧。
